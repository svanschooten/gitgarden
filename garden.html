Reading the garden

Colour — the biome a file's extension belongs to.
Withering — low health; the file has been left alone.
Shade — each file gets its own tint, so neighbours stay distinct.
Speckle — indentation complexity; denser means more deeply nested.
Outline — the boundary between two files.
Area — line count, within a biome sized by file count.
